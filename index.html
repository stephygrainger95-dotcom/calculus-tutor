这是什么：一套多智能体协作的学习支持平台，覆盖两大平级场景——课内微积分：诊疗师诊断建档、教官攻防训练、分析师生成学情报告，三个智能体共享同一个错题本数据底座；课外竞赛：数据分析师接收 Excel 数据表，由代码精确计算统计量，AI 生成分析报告与可视化图表。

为什么通用大模型替代不了：通用大模型对话一关就忘，只对答案负责；本系统能记住每个学生错在哪、识别"答案碰巧对但过程错误"的假掌握；数据分析场景中所有数字由代码计算而非模型估算，保证零错误。

技术架构：基于 Dify 工作流编排——课内线：多模态识别 → 知识库检索 → 错因诊断 → 结构化提取 → 飞书多维表格读写；竞赛线：文档提取 → 代码执行统计计算 → LLM 报告生成 → ECharts 自动绘图。私有知识库含 30+ 定理易错点卡片，经数学专业人工校验。
